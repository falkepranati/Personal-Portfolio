# Personal Portfolio Website

A modern and responsive personal portfolio website created to showcase my skills, projects, education and professional profile.

## About the Project

This portfolio website presents my professional information in an attractive and organized format. It helps visitors learn about my background, technical skills and projects.

## Features

- Professional homepage
- About Me section
- Education details
- Technical skills section
- Projects showcase
- Resume information
- LinkedIn profile link
- Contact section
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
